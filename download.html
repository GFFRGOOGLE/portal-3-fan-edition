📥 УСТАНОВКА

Инструкции для Windows, Android, macOS
Главная Установка Моды для Minecraft Чит-коды Поддержка Чат

🖥️ Windows

Скачайте NW.js SDK с официального сайта, создайте папку game, поместите index.html и package.json, перетащите папку на nw.exe.

📱 Android

Откройте страницу с игрой в Chrome, нажмите «Добавить на главный экран» или используйте PWA2APK.

🍏 macOS

Скачайте NW.js для macOS, поместите игру в папку, запустите nwjs.app.
